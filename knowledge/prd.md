## 1. Problem statement

Indian working parents want to raise well-rounded children — not just academically strong, but physically healthy, creatively expressive, morally grounded, and socially connected. The challenge is not intent — it is **visibility and follow-through**. Days go by, weeks blur together, and parents often realise too late that their child hasn't read a book in three weeks, or hasn't had unstructured outdoor time, or hasn't had a meaningful family dinner in days.

There is no tool today that:

- Lets parents log their child's daily experiences in natural language
- Tracks balance across multiple dimensions of a child's growth
- Actively nudges parents when a domain is being neglected
- Builds a living memory of the child's journey — books read, foods loved, skills mastered
- Produces a meaningful monthly reflection report

**Rooted and Rising** fills this gap.

## 3. Goals

### Primary goals

1. Make it **effortless** to log what a child did — text, photo, or voice
2. Give parents **clear visibility** into which growth domains are balanced and which are lagging
3. **Nudge proactively** when a domain goes quiet, with warmth — not alarm
4. Build a **living library** of the child's experiences, tastes, and skills
5. Produce a **monthly PDF report** that parents can treasure and share

### Non-goals (v1.0)

- Multi-child support (future)
- WhatsApp integration (future)
- Teacher/school portal (future)
- Real-time collaboration between two parents (future)

## 5. Core features

### 5.1 Journal

- Free text, image upload, voice note (Whisper-transcribed)
- `JournalAgent` classifies into 1 of 5 domains, extracts structured fields
- Auto-detects library candidates (book titles, foods, activity names)
- Stores `JournalEntry` with media references

### 5.2 Balance analyser

- Rolling 7-day and 30-day windows
- Coverage score per domain; flags `balanced` / `low` / `neglected`
- Configurable thresholds (`NEGLECTED_THRESHOLD_DAYS`, `LOW_THRESHOLD_DAYS`)
- Produces `GapReport`

### 5.3 Planner (hybrid)

- AI suggestions from `PlannerAgent` based on `GapReport`
- Parent-defined todos entered directly in the dashboard
- `source: "ai" | "parent"` on every `PlannedActivity`
- Parent todos always displayed and reported above AI suggestions

### 5.4 Library (3 collections)

- **Books** — title, author, genre, dates, status, child rating, cover image
- **Foods** — name, category, first tried, status (loves/tried/dislikes), photo
- **Activities** — name, domain, first done, status (tried/enjoys/mastered), frequency
- Auto-populated by `LibraryAgent` from journal entries; parent can add/edit directly

### 5.5 Nudge system

- `NudgeAgent` runs nightly
- Fires in-app banner for each neglected domain
- Warm, specific message — names domain and last activity date
- Throttle: max 1 nudge per domain per 48 hours

### 5.6 Monthly PDF report

- Cover page, domain balance chart, domain summaries with photo thumbnails
- Library milestones, planned vs completed, AI-generated growth notes
- Generated by WeasyPrint from HTML/CSS template
- Available for download from dashboard

## 6. Agent contracts

```
JournalAgent       in: RawInput(text, images[], audio_path)    out: JournalEntry
BalanceAnalyser    in: AnalysisRequest(child_id, window_days)  out: GapReport
PlannerAgent       in: GapReport                               out: WeeklyPlan
LibraryAgent       in: JournalEntry                            out: List[LibraryItem]
NudgeAgent         in: GapReport                               out: List[NudgeMessage]
ReportAgent        in: MonthlyReportRequest                     out: MonthlyReport
```

---

## 7. Engineering principles

| Principle             | Implementation                                                |
| --------------------- | ------------------------------------------------------------- |
| Single responsibility | Each agent does exactly one thing                             |
| Retry on failure      | Exponential backoff, max 3 retries, logged                    |
| Structured logging    | Every agent run emits a structured JSON log event             |
| Graceful degradation  | Partial failures return what's available, flagged in output   |
| Human-in-the-loop     | Planner output requires parent confirmation before finalising |
| Typed contracts       | All agent I/O via Pydantic v2 models — no raw dicts           |

## 13. Glossary

| Term               | Definition                                                     |
| ------------------ | -------------------------------------------------------------- |
| **JournalEntry**   | A single log of something the child did, with optional media   |
| **GapReport**      | Domain coverage analysis showing balanced/low/neglected status |
| **WeeklyPlan**     | AI suggestions + parent todos for the coming week              |
| **LibraryItem**    | A book, food, or activity in one of the three collections      |
| **NudgeMessage**   | A targeted parent alert about a neglected domain               |
| **Coverage score** | Computed measure of domain activity over a time window         |
| **HITL gate**      | Human-in-the-loop pause requiring parent confirmation          |
